# Color Gradient Examples

This directory contains examples demonstrating the usage of the `ColorGradient` widget for the `Textual` library. The `ColorGradient` widget allows users to select colors by sliding a gradient bar, providing a visual representation of color selection.

## simple.py

A basic example demonstrating the usage of the `ColorGradient` widget.

## color_picker.py

An advanced example demonstrating the usage of the `ColorGradient` widget as a custom color picker.

Note: Requires the [textual-thin-slider](https://pypi.org/project/textual-thin-slider/) package to be installed.
